Core Philosophy

设计理念

每一行代码、每一个交互，都围绕着同一个目标：让山野中的你多一份安心，少一分担忧。

安全第一

SOS 紧急求救系统，一键触发，5 秒倒计时确认，防止误触。实时 GPS 坐标自动附带的求救信息，让每一次出行都有备无患。

轻量极速

纯原生 JavaScript + CSS 实现，无任何外部框架依赖。单个 HTML 文件承载全部应用，网络再差也能秒开，体验如原生 App。

山友共创

路书分享、装备管理、队友定位……我们相信好的工具应由山友共同打磨。开源 MIT 协议，欢迎每一位热爱山野的你参与贡献。

Features

核心功能

十大功能模块，覆盖从出发前的规划到回程后的分享全流程。

追光计划

追光计划

智能推荐最佳日出观赏日和云海观赏日。基于云量、风力、降水量、空气质量四维综合评分，自动计算最优日期。告别盲目等待，让追光更有把握。

云海预测 日出推荐 多维评分 天气聚合
青山不迷

青山不迷 — 轨迹守护

GPS 实时记录徒步、骑行等户外轨迹。内置 Web Worker 后台计算总距离、累计爬升/下降、海拔范围，自动评估轨迹难度（1-5 星），支持离线缓存和 GPX 导出。

实时 GPS Web Worker 难度评估 GPX 导出
天气

精准天气预报

和风天气 API 驱动，提供实时天气、逐小时预报、7 日天气预报，含穿衣指数、户外建议、AQI 空气质量等贴心提示。支持城市切换和自动刷新。

7 日预报 穿衣指数 AQI 质量 自动刷新
AI 助手

AI 户外助手

内置 AI 问答助手，可查询深圳山峰信息（梧桐山、七娘山、马峦山等）、获取日出/云海建议、推荐新手路线、提供户外安全注意事项。快捷问题卡片一键直达。

山峰数据 路线推荐 安全提示 快捷卡片
